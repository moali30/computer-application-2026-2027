One Sample T-Test

When and how

When?

When we compare the mean of one quantitative variable with a hypothesised value μ0 given in the question.

H0: μ = μ0

H1: μ ≠ μ0

Enter the data, then follow the menu path above.

3

5

Computer Application · Section 4

09

Test Value is the key box: leave it empty and SPSS compares the mean with zero. The confidence level in Options only changes the confidence interval; we use it to know α.
